telão

Telão para Windows

Chat, call e compartilhamento de tela com o som do PC, num programa próprio. Abre pelo menu Iniciar, fica na bandeja e avisa quando chega mensagem.

Carregando… Prefere não instalar? Use no navegador.
  1. Clique em baixar. O arquivo Telao-Setup.exe vai para a pasta Downloads.
  2. Abra o arquivo. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações → Executar assim mesmo.
  3. Pronto: o Telão abre sozinho e cria um atalho na área de trabalho.
  • Tela com somEscolha a tela ou a janela do jogo, com o áudio do PC.
  • Na bandejaFechar a janela deixa o Telão ligado para receber chamadas.
  • NotificaçõesAviso do Windows para mensagens e chamadas.
  • Atualiza sozinhoVersões novas entram quando você fecha o app.
